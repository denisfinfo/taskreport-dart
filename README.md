# TaskReport Dart

## Sobre o projeto

O TaskReport Dart é um simulador de tratamento de dados de tarefas em Dart.
O projeto simula o retorno de um API por meio de uma lista de mapas, transforma esses dados em objetos e gera relatórios com base nos status das tarefas.

## Objetivo

Praticar os principais conceitos do Módulo 01:
- Lógica de programação
- Linguagem Dart
- Tipos de dados
- Estruturas de decisão
- Estruturas de repetição
- Funções e Arrow functions
- Coleções (Lists, Maps, e Sets)
- Métodos de coleção
- Classes, Objetos, Atributos e Métodos
- Construtores
- Encapsulamento com modificadores de acesso
- Herança e Polimorfismo com @override
- GitHub, GitFlow e Kanban

## 🚀 Como executar

Executar o arquivo 'main.dart' no ambiente utilizado em aula.

Exemplo pelo terminal:
```bash

```

*Ou execute pelo DartPad, caso orientado pelo docente.*
